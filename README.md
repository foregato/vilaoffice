# Vila Office — Site institucional

React + Vite + Tailwind CSS.

## Rodar localmente
```
npm install
npm run dev
```

## Build de produção
```
npm run build
```
Gera a pasta `dist/` pronta para deploy (Vercel, Netlify, etc).

## Editar conteúdo
- **Salas:** `src/data/salas.js` — status, descrição e dados do ocupante de cada uma das 10 salas.
- **Profissionais:** `src/data/profissionais.js` — lista de profissionais exibidos na seção "Profissionais".
- **Contato/WhatsApp/endereço:** `src/data/config.js` — número de WhatsApp, mensagem padrão e endereço usado no mapa.

Campos marcados com `// TODO` estão vazios de propósito — nenhuma informação foi inventada.
